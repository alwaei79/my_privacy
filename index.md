# Shorts Agent

Shorts Agent is a personal automation tool used by the owner of the YouTube channel
**Bebasata | ببساطة** (economics and technology explained simply, in Arabic).

## What it does

- Takes long educational videos that the owner published on his own YouTube channels.
- Cuts the strongest moments into short vertical clips (9:16) with Arabic subtitles.
- Uploads those clips to the owner's own accounts: YouTube Shorts, TikTok, Instagram Reels and Facebook Reels.

The tool runs only on the owner's computer and is used only with the owner's own accounts.
It is not offered to other users.

## Google / YouTube data

The tool uses the YouTube Data API only to upload videos to the owner's channel
(scope `youtube.upload`) and to read the channel name (scope `youtube.readonly`).
