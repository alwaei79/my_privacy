# Privacy Policy – Shorts Agent

_Last updated: November 11, 2026_

Shorts Agent is a personal tool that uploads short videos to the YouTube channel and social
media accounts of its owner. It is used only by its owner and is not offered to the public.

## Data the app accesses

- **YouTube (Google) account:** with the owner's permission, the app uses the YouTube Data API
  to upload videos to the owner's channel and to read the channel name to confirm the correct
  channel is connected.
- **Video files and subtitles** created by the owner from his own published videos.

## How data is used and stored

- Access tokens are stored only on the owner's own computer and are used only to publish
  the owner's videos.
- The app does not collect, sell or share any personal data, and it does not access data of
  any other users.
- The app does not show advertising.

## Google API Services User Data Policy

Shorts Agent's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Revoking access

Access can be removed at any time from <https://myaccount.google.com/permissions>.
